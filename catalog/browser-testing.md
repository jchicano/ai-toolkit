# Browser Automation & Testing

**Last Updated:** 2026-11-10

- **[Playwright](https://github.com/microsoft/playwright)** — Cross-browser automation library for testing and web automation. Supports Chromium, Firefox, and WebKit. Works with Claude Code for browser-based workflows. Install: `npm install -g playwright`
- **[Browser MCP](https://registry.modelcontextprotocol.io/)** — Web automation over MCP: navigation, clicking, screenshots, DOM interaction.

- **[agent-desktop](https://github.com/vercel-labs/agent-desktop)** — Computer-use CLI for AI agents: operate macOS/Windows/Linux desktop apps via the OS accessibility tree (refs, no pixel matching). CLI + C library; no model inside. Site: [agent-browser.dev/desktop](https://agent-browser.dev/desktop). Install: `npm install -g agent-desktop` or `brew install agent-desktop`.

- **[agent-qa](https://vostride.com)** — Natural-language web, Android and iOS QA with persistent memidex memory, validated self-improvement and step screenshots; CLI, local dashboard and MCP. Node.js 24+; $0 for permitted local FSL-1.1-ALv2 use, with separate model/device costs. [Source](https://github.com/vostride/agent-qa).

See also: [Playwright quick commands](../claude-code/quick-commands.md#playwright).
