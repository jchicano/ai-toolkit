# Launch & Sharing

**Last Updated:** 2026-10-31

Skills and tools that help ship or promote a project after you build it.

- **[Brag](https://github.com/latent-spaces/brag)** — Agent skill (`/brag`) that turns the project you just built into a short, shareable launch video (music, motion, share copy). Powered by Hyperframes; includes lean `/brag-slim`. Site: [latent-spaces.github.io/brag](https://latent-spaces.github.io/brag/). Web: [letsbrag.app](https://letsbrag.app). Install (Claude Code): `/plugin marketplace add latent-spaces/brag` then `/plugin install brag@brag`. Or: `npx skills add https://github.com/latent-spaces/brag --skill brag-slim`
- **[OpenShorts](https://github.com/mutonby/openshorts)** — Open-source AI clip generator (OpusClip alternative): long video → viral 9:16 Shorts/TikToks/Reels with moment detection, face tracking, subtitles, dubbing. Self-host with Docker (MIT) or cloud. MCP server + API for agents. Site: [openshorts.app](https://www.openshorts.app/).
