# AI Agent Orchestration & Routing

**Last Updated:** 2026-11-10

Tools for coordinating, routing, and running AI coding agents.

## Frameworks & orchestrators

- **[ECC — Agent Harness Operating System](https://github.com/affaan-m/ECC)** — Complete system for AI agent workflows: 68 specialized agents, 292+ reusable skills, runtime hooks for deterministic checks, security scanning (AgentShield), and a memory vault. Install: `npx ecc-universal@2.2.1 setup --mode claude-plugin --scope project`
- **[CLI Agent Orchestrator (CAO)](https://github.com/awslabs/cli-agent-orchestrator)** — Multi-agent coordination platform. A supervisor coordinates specialist AI coding assistants (Claude Code, Cursor, GitHub Copilot CLI, etc.) on parallel or sequential tasks. Web UI, persistent memory, workflow automation, EKS deployment support.
- **[Spec Kit](https://github.com/github/spec-kit)** — GitHub’s open-source toolkit for Spec-Driven Development (and bug-fix / idea-assessment processes) with coding agents: templates, extensions, presets, workflows. Docs: [github.github.io/spec-kit](https://github.github.io/spec-kit/). Install: `uv tool install specify-cli` then `specify init <project> --integration <agent>`.
- **[The Agency (agency-agents)](https://github.com/msitarzewski/agency-agents)** — Large roster of specialized AI agent personalities (engineering, design, marketing, security, etc.) with workflows and deliverables. Install via desktop app ([agencyagents.app](https://agencyagents.app)) or `./scripts/install.sh` into Claude Code, Cursor, Codex, Gemini, and more.
- **[herdr](https://github.com/herdrdev/herdr)** — Terminal runtime/multiplexer for coding agents: detachable sessions, multi-machine panes, working/blocked/idle status, agent-native CLI/socket API. Site: [herdr.dev](https://herdr.dev). Homebrew: `brew install herdr`.
- **[CLI-Anything](https://github.com/HKUDS/CLI-Anything)** — Make any software agent-native via generated CLIs (hub of community harnesses for CAD, office apps, editors, etc.). Hub: [clianything.cc](https://clianything.cc/) / [hkuds.github.io/CLI-Anything](https://hkuds.github.io/CLI-Anything/). Install hub: `pip install cli-anything-hub` then `cli-hub install <name>`.
- **[Orca](https://github.com/stablyai/orca)** — Orchestrator for fleets of coding agents (Claude Code, Codex, OpenCode, Pi, …): parallel git worktrees, desktop + mobile companion, remote runtime. Use your own subscriptions. Site: [orca.dev](https://orca.dev) / [onorca.dev](https://onorca.dev).
- **[T3 Code](https://github.com/pingdotgg/t3code)** — Open-source control surface for the coding agents on your machine (Claude Code, Codex, Cursor CLI, Grok Build, OpenCode, Antigravity, fx) using your own subscriptions. Local web app, Electron desktop app, and iOS/Android apps for remote control. Site: [t3.codes](https://t3.codes). Install: `curl -fsSL https://t3.codes/install.sh | sh`, then run `t3` (or try once with `npx t3@latest`). Desktop: `brew install --cask t3-code` / `winget install T3Tools.T3Code`.
- **[Paradev](https://github.com/paradevai/paradev)** (formerly Superset) — Open-source workspace for running many coding agents (Claude Code, Codex, OpenCode, Cursor, …) in parallel on separate branches/worktrees, with one place to review diffs, plus automations and cloud workspaces. macOS desktop app. Site: [paradev.com](https://paradev.com).
- **[Conductor](https://www.conductor.build/)** — Run a team of coding agents (first-party Claude Code, Codex, Cursor, OpenCode) in isolated cloud microVM sandboxes or locally; bring your own subscriptions/keys, multiplayer workspaces. Commercial. Docs: [docs.conductor.build](https://docs.conductor.build). Note: Conductor announced it is joining Meta.
- **[Traycer](https://github.com/traycerai/traycer)** — Open-source AI orchestration desktop app (“nerve center” for agentic coding): BYOA, shared context across models/providers, agent-to-agent loops, collaboration boards. Site: [traycer.ai](https://traycer.ai). Docs: [docs.traycer.ai](https://docs.traycer.ai).
- **[OpenAgents Control (OAC)](https://github.com/darrenhinde/OpenAgentsControl)** — Agent framework on top of OpenCode: plan-first workflows with approval gates, agents that load your project patterns as context, editable markdown agents, built-in testing and code review. Model agnostic. Install: `curl -fsSL https://raw.githubusercontent.com/darrenhinde/OpenAgentsControl/main/install.sh | bash -s developer`. Note: current version targets OpenCode v1; a rewrite is announced.
- **[Ruflo](https://github.com/ruvnet/ruflo)** — Agent meta-harness for Claude Code, Codex, and more: multi-agent swarms, adaptive memory, federation, MCP, and a visual console. Site: [cognitum.one](https://cognitum.one). Install: `npx ruflo@latest init` (or Claude Code plugins via `/plugin marketplace add ruvnet/ruflo`).
- **[Loop Engineering](https://github.com/cobusgreyling/loop-engineering)** — MIT pattern library + CLI for running coding agents in loops instead of prompting by hand: patterns like daily triage, PR babysitter, CI/dependency sweepers and changelog drafter, plus `loop-audit`, `loop-init`, `loop-cost` tools. Works with Claude Code, Codex, OpenCode, Grok. Site: [showcase](https://cobusgreyling.github.io/loop-engineering/). Start: `npx @cobusgreyling/loop init . --pattern daily-triage --tool claude`.

## Coding agents (CLI / IDE)

- **[Cline](https://github.com/cline/cline)** — Autonomous coding agent as IDE extension, desktop app, CLI (`npm i -g cline`), or SDK. Site: [cline.bot](https://cline.bot). Docs: [docs.cline.bot](https://docs.cline.bot).
- **[Pi](https://github.com/earendil-works/pi)** — Minimal, extensible coding-agent harness (unified LLM API, agent loop, TUI, CLI/SDK). Customize with extensions, skills, prompt templates, themes; share as Pi packages. Site: [pi.dev](https://pi.dev). Install: `curl -fsSL https://pi.dev/install.sh | sh` (or `npm i -g --ignore-scripts @earendil-works/pi-coding-agent`).
- **[OpenCode](https://github.com/anomalyco/opencode)** — Open-source AI coding agent (TUI, desktop, IDE): multi-session, any provider via Models.dev, free models included. Site: [opencode.ai](https://opencode.ai). Install: `curl -fsSL https://opencode.ai/v2/install | bash` (or `brew install anomalyco/tap/opencode-v2` / `npm i -g @opencode/cli@latest`).
- **[Command Code](https://commandcode.ai)** — Coding agent tuned for open models (tool-call repairs, token-efficient tools, taste learning). Alternative to Claude Code / Cursor / OpenCode / Copilot; also used as a model API by community providers. Site: [commandcode.ai](https://commandcode.ai).
- **[Freebuff](https://github.com/CodebuffAI/codebuff)** — Free coding agent (browser, desktop, CLI): frontier models funded by ads, no subscription. Site: [freebuff.com](https://freebuff.com/).
- **[Qoder](https://qoder.com)** — Agentic coding platform / AI programming IDE: conversational coding, completion, code generation; VS Code & JetBrains. Site: [qoder.com](https://qoder.com).
- **[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)** — Open-source agent harness (“everything is a plugin” via Cordis): docs, data, coding, scheduled tasks; desktop + web; composable community plugins. Site: [deepseek.com/en/harness](https://www.deepseek.com/en/harness/).
- **[fx](https://fx.sh/)** — Tiny open-source (Apache-2.0) native coding-agent CLI by Vercel Labs, written in Zig (~6 MiB); Unix-shell style, model-agnostic, embeddable (`libfx`). Source: [vercel-labs/fx](https://github.com/vercel-labs/fx). Install: `curl -fsSL https://fx.sh/setup.sh | bash`.
- **[Kiro](https://kiro.dev/)** — AWS agentic engineering system (IDE, CLI, web, mobile, and Kiro Crew): specs, local or cloud sessions, and persistent agents. Free to start (sign in with Google, GitHub, or AWS Builder ID). Downloads: [kiro.dev/downloads](https://kiro.dev/downloads/). CLI: `curl -fsSL https://cli.kiro.dev/install | bash`. Homebrew: `brew install --cask kiro` (IDE) / `brew install --cask kiro-cli`.
- **[Kilo Code](https://kilo.ai/)** — Open-source coding agent for VS Code, JetBrains, CLI, desktop, and cloud; 500+ models at cost (no markup) or your own keys. Source: [Kilo-Org/kilocode](https://github.com/Kilo-Org/kilocode). CLI: `curl -fsSL https://kilo.ai/cli/install | bash`.
- **[CodeBuddy](https://www.codebuddy.ai/)** — Tencent Cloud AI coding assistant: IDE, editor plugins (VS Code / JetBrains), and CLI (CodeBuddy Code) from requirements and design through code and deploy (Hunyuan and other models). Docs: [Tencent Cloud product overview](https://intl.cloud.tencent.com/document/product/1256/77266).
- **[Crow](https://crow-ai.dev/)** — Free open-source (MIT) ACP-native coding agent (`crow-cli`) plus Crow ADE editor (a Zed fork; unaffiliated with Zed Industries). BYOK. Install: `curl -fsSL https://crow-ai.dev/install.sh | bash`.
- **[Devin](https://devin.ai/)** — Autonomous software engineer by Cognition: cloud or local, own VMs/browser for tests, Slack/Teams, review and automations. Commercial (Free; Pro $20/mo; Max $200/mo; Teams/Enterprise). Pricing: [devin.ai/pricing](https://devin.ai/pricing).
- **[DimAgent](https://dimagent.cn/en)** — Local desktop and CLI agent that orchestrates a team of models on your computer (browser, Office tools, MCP); conversations stay on-device. Free and paid credit plans. Desktop: [download](https://dimagent.cn/en/download). CLI: `npm install -g dimcode@latest` then `dim`.
- **[Dirac](https://dirac.run/)** — Open-source efficiency-focused coding agent for real codebases (goal mode, hash-anchored edits, AST tools, subagents); CLI and VS Code. Source: [dirac-run/dirac](https://github.com/dirac-run/dirac). Install: `npm install -g dirac-cli`.
- **[fast-agent](https://fast-agent.ai/)** — Open-source agent harness (Python) for coding, building, and evaluating agents; strong MCP, skills, ACP, and A2A support; API keys or subscription logins (Codex, Copilot). Source: [evalstate/fast-agent](https://github.com/evalstate/fast-agent). Try: `uvx fast-agent-mcp@latest -x`.
- **[Factory Droid](https://factory.com/product/cli)** — Factory’s interactive terminal coding agent (Droids): sessions, missions, skills/MCP/hooks; same agents across TUI, IDE, web, Slack. Docs: [docs.factory.com](https://docs.factory.com/droid-cli/quickstart.md). Install: `curl -fsSL https://app.factory.ai/cli | sh` (or `brew install --cask droid` / `npm install -g droid`), then `droid`.
- **[goose](https://goose-docs.ai/)** — Open-source general-purpose local AI agent (desktop, CLI, API; Rust) founded by Block, now stewarded by the Agentic AI Foundation (Linux Foundation). Official repo: [aaif-goose/goose](https://github.com/aaif-goose/goose) (moved from `block/goose`). Any LLM or existing Claude/ChatGPT/Gemini subscriptions. CLI: `curl -fsSL https://github.com/aaif-goose/goose/releases/download/stable/download_cli.sh | bash`.
- **[Junie](https://junie.jetbrains.com/)** — JetBrains AI coding agent: Junie CLI in the terminal and Junie Local inside JetBrains IDEs; BYOK (10+ models). Free to start, no credit card. Source: [JetBrains/junie](https://github.com/JetBrains/junie). Install: `curl -fsSL https://junie.jetbrains.com/install.sh | bash` (or `brew install --cask junie`).
- **[Kimi Code](https://moonshotai.github.io/kimi-code/en/)** — Moonshot AI’s open-source (MIT) terminal coding-agent CLI (`kimi`): skills, hooks, sub-agents, MCP, video input. Source: [MoonshotAI/kimi-code](https://github.com/MoonshotAI/kimi-code). Install: `curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash` (or `brew install kimi-code`).
- **[MiniMax Code](https://agent.minimax.io/)** — MiniMax’s open-source terminal coding agent (`mcode`): interactive TUI, headless `mcode exec`, and ACP. Source: [MiniMax-AI/minimax-code](https://github.com/MiniMax-AI/minimax-code). Docs: [agent.minimax.io/docs/cli/quick-start](https://agent.minimax.io/docs/cli/quick-start). Install: `curl -fsSL https://filecdn.minimax.chat/public/install.sh | bash`.
- **[Mistral Vibe](https://mistral.ai/products/vibe/)** — Mistral’s AI assistant and coding agent (formerly Le Chat): CLI, VS Code / JetBrains / Zed via ACP, and remote agents. Free, Pro, Team, and Enterprise plans. Source: [mistralai/mistral-vibe](https://github.com/mistralai/mistral-vibe). CLI: `curl -LsSf https://mistral.ai/vibe/install.sh | bash` (or `brew install mistral-vibe`).
- **[Qwen Code](https://qwenlm.github.io/qwen-code-docs/en/users/overview/)** — Alibaba / Qwen’s open-source (Apache-2.0) agentic coding CLI (`qwen`) in the terminal (VS Code companion in beta). Use a Qwen Plus/Pro subscription, QwenCloud, ModelStudio, or third-party keys. Source: [QwenLM/qwen-code](https://github.com/QwenLM/qwen-code). Install: `curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen-standalone.sh | bash` (or `brew install qwen-code`).
- **[Zed](https://zed.dev/)** — Open-source high-performance collaborative IDE by Zed Industries (creators of Atom and Tree-sitter); built-in Agent Panel plus ACP to connect other coding agents. Source: [zed-industries/zed](https://github.com/zed-industries/zed). Homebrew: `brew install --cask zed`.
- **[Stakpak](https://stakpak.dev/)** — Open-source (Apache-2.0, Rust) agent that runs on your machines 24/7 to keep apps running in production (auto-healing, cost watchdog, secret redaction, network sandbox)—not a typical coding agent. Source: [stakpak/agent](https://github.com/stakpak/agent). Install: `curl -sSL https://stakpak.dev/install.sh | sh`.
- **[VT Code](https://github.com/vinhnx/VTCode)** — Open-source (MIT/Apache-2.0) local-first coding agent for the terminal and a native macOS desktop app; planning, sandboxed policy, MCP, and hosted or local models. Site: [vinhnx.github.io/VTCode](https://vinhnx.github.io/VTCode/). Install: `curl -fsSL https://raw.githubusercontent.com/vinhnx/VTCode/main/scripts/install.sh | bash` (or `brew install vtcode`).
