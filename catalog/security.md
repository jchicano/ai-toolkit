# Security & Pentesting

**Last Updated:** 2026-11-10

AI agents for authorized security testing. Only use them against systems you own or have written permission to test.

- **[PentAGI](https://github.com/vxcontrol/pentagi)** — MIT, self-hosted multi-agent system for autonomous penetration testing: describe a target and goal in plain language, and specialized agents plan the work, run 20+ tools (nmap, Metasploit, sqlmap…) in an isolated Docker sandbox, keep memory in PostgreSQL/pgvector, and produce a report. Supports many LLM providers. Site: [pentagi.com](https://pentagi.com/). Install: interactive installer for Linux/macOS/Windows (Docker Compose); see the [Quick Start](https://github.com/vxcontrol/pentagi#quick-start).
