# Diagrams & Visualization

**Last Updated:** 2026-10-28

Skills and tools that turn ideas, plans, or codebases into interactive diagrams.

- **[Archify](https://github.com/tt-a1i/archify)** — Agent skill that turns an idea, plan, or codebase into a beautiful interactive HTML diagram. Works with Claude Code, Codex, Cursor, and OpenCode. Site: [archify.si](https://archify.si). Install: `npx skills add tt-a1i/archify -g`
