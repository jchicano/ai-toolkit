# Dev Utilities (GitHub URL tricks)

**Last Updated:** 2026-11-09

Drop-in GitHub URL swaps that turn any repo into diagrams, LLM context, reverse prompts, or live docs for agents.

- **[GitReverse](https://www.gitreverse.com/)** — Reverse-engineer any codebase or website into a prompt. Trick: replace `github` with `gitreverse` in any GitHub URL (e.g. `github.com/owner/repo` → `gitreverse.com/owner/repo`). Site: [gitreverse.com](https://www.gitreverse.com/).
- **[GitDiagram](https://github.com/ahmedkhaleel2004/gitdiagram)** — Free interactive architecture diagrams (and short explainer videos) for any GitHub codebase. Trick: replace `hub` with `diagram` in any GitHub URL (e.g. `github.com/owner/repo` → `gitdiagram.com/owner/repo`). Site: [gitdiagram.com](https://gitdiagram.com).
- **[Gitingest](https://github.com/coderamp-labs/gitingest)** — Turn any Git repo into a prompt-friendly text digest for LLMs. Trick: replace `hub` with `ingest` in any GitHub URL (e.g. `github.com/owner/repo` → `gitingest.com/owner/repo`). Site: [gitingest.com](https://gitingest.com). Install: `pip install gitingest`.
- **[GitMCP](https://github.com/idosal/git-mcp)** — Free remote MCP server that turns any GitHub project into up-to-date docs/code for agents (cuts hallucinations). Trick: replace `github.com` with `gitmcp.io` (e.g. `github.com/owner/repo` → `gitmcp.io/owner/repo`, or use `gitmcp.io/docs` for a generic server). Site: [gitmcp.io](https://gitmcp.io).
