# Media & Voice

**Last Updated:** 2026-11-13

Screen recording, short-form video, and local voice tools useful for demos and content.

- **[Recordly](https://github.com/webadderallorg/recordly)** — Open-source screen recorder and editor for polished demos and walkthroughs (auto-zoom, cursor polish, webcam bubble, timeline). macOS 14+, Windows 10+, Linux. Site: [recordly.dev](https://recordly.dev). Homebrew: `brew install --cask recordly`.
- **[TextMatchCut](https://www.textmatchcut.app/)** — Free browser-based editor for text match cuts (newspaper-clipping / highlight-word effect). Type a phrase, highlight a word, export HD MP4; no signup, no watermark. Site: [textmatchcut.app](https://www.textmatchcut.app/).
- **[VoiceStudio](https://github.com/debpalash/voicestudio)** — Fully local open-source ElevenLabs alternative: voice cloning, voice design, video dubbing, dictation, transcription, and audiobooks in 646 languages. Site: [voicestudio.sh](https://voicestudio.sh). Install: `curl -fsSL https://voicestudio.sh/install | sh` (or download from [releases](https://github.com/debpalash/voicestudio/releases/latest)).
- **[VibeVoice](https://github.com/microsoft/VibeVoice)** — Microsoft’s open-source family of frontier voice models: long-form ASR (who/when/what, 60-minute single-pass, 50+ languages, streaming and CPU/BitNet variants) and realtime streaming TTS (0.5B). Site: [microsoft.github.io/VibeVoice](https://microsoft.github.io/VibeVoice). Weights: [Hugging Face collection](https://huggingface.co/collections/microsoft/vibevoice-68a2ef24a875c44be47b034f). Note: Microsoft removed the original long-form VibeVoice-TTS code from this repo after misuse; ASR and realtime TTS remain.
- **[video-use](https://github.com/browser-use/video-use)** — Open-source skill for editing videos with coding agents (Claude Code, Codex, Hermes, OpenClaw, …): drop raw footage in a folder, chat, get `final.mp4` (filler-word cuts, color grade, subtitles, animation overlays, self-eval). Site: [video-use.com](https://video-use.com). Setup: point your agent at the repo and have it follow `install.md`, or `git clone` and `uv sync` (needs `ffmpeg` and an ElevenLabs API key for transcription).
- **[Summarize](https://github.com/steipete/summarize)** — CLI and Chrome/Firefox extension that extracts text and summarizes web pages, files, YouTube, podcasts, and other audio/video. Site: [summarize.sh](https://summarize.sh). Install: `brew install summarize` (or `npm install --global @steipete/summarize`). Chrome: [Summarize Side Panel](https://chromewebstore.google.com/detail/summarize/cejgnmmhbbpdmjnfppjdfkocebngehfg).
- **[Kimu Video Editor](https://github.com/trykimu/videoeditor)** — Open-source, AI-assisted video editor (CapCut/Canva-style): multi-track timeline, realtime preview, a “Vibe” assistant that turns a description into edits, media library, and cloud-synced projects. Site: [trykimu.com](https://trykimu.com). Self-host: `docker compose up -d`.
