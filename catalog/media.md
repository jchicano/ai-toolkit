# Media & Voice

**Last Updated:** 2026-11-09

Screen recording, short-form video, and local voice tools useful for demos and content.

- **[Recordly](https://github.com/webadderallorg/recordly)** — Open-source screen recorder and editor for polished demos and walkthroughs (auto-zoom, cursor polish, webcam bubble, timeline). macOS 14+, Windows 10+, Linux. Site: [recordly.dev](https://recordly.dev). Homebrew: `brew install --cask recordly`.
- **[TextMatchCut](https://www.textmatchcut.app/)** — Free browser-based editor for text match cuts (newspaper-clipping / highlight-word effect). Type a phrase, highlight a word, export HD MP4; no signup, no watermark. Site: [textmatchcut.app](https://www.textmatchcut.app/).
- **[VoiceStudio](https://github.com/debpalash/voicestudio)** — Fully local open-source ElevenLabs alternative: voice cloning, voice design, video dubbing, dictation, transcription, and audiobooks in 646 languages. Site: [voicestudio.sh](https://voicestudio.sh). Install: `curl -fsSL https://voicestudio.sh/install | sh` (or download from [releases](https://github.com/debpalash/voicestudio/releases/latest)).
